# Settings & appearance

Open **Settings** from the footer. Choices are remembered in your browser and applied the next time you open the app.

## Theme

Choose a light or dark theme. The palette is applied through CSS variables, so every surface of the app changes together. The available themes include **Dracula**, **Solarized Dark**, **Monokai** and **Light**.

## Text size

The footer's **−** / **+** step the editor text between 50% and 200% of your browser's default font size, with **Reset size** back to 100%. Because it scales from your browser's size, it respects the text size you have already chosen for accessibility.

## Decimal precision

Results show up to **3 decimal places** by default. Set the number of places from 0 to 10 in **Settings → Decimal precision**.

A truncated result ends with an ellipsis (`…`); the calculation itself keeps full precision, so later lines that use the result are not affected by the display choice.

## Clock

Clock times use a 24-hour format by default. **Settings → Clock** switches to a 12-hour format with `am`/`pm`.

## Measurement system

Cooking volume units follow **Settings → Measurement system** — **Metric** (default), **US customary** or **Imperial**. It sets `cup` to 250, 236.6 or 284.1 ml, and changes `tsp`, `tbsp`, `fl oz`, `pint`, `quart` and `gallon` with it. See [Units & measures](/docs/units/).

## Language

The interface, the Examples and these documentation pages ship in **English**, **Portuguese** and **Spanish**. Math Notes starts in your system language and can be changed in **Settings → Language**. The calculator syntax itself stays English regardless of the interface language.
