# Math Notes documentation

Math Notes is an inline calculator that runs entirely in your browser. Type calculations line by line and each result appears beside it as dimmed ghost text, with a running total at the bottom. It is inspired by [Numi](https://numi.app) and [Soulver](https://soulver.app).

This guide covers every feature in depth. If you want a quick reference while you work, open **Help** inside the app — this documentation is the long-form version.

## How to read this guide

Each page focuses on one area and builds from the simple case to the edge cases. Example blocks are real calculations: use **Copy** to take one away, or **Open in Math Notes** to try it in the app in a new tab. Nothing you open replaces the sheet you already have.

Everything runs locally. Your sheets are saved in your browser's storage and are never sent to a server.

## What Math Notes is not

It is not a general-purpose programming environment and it is not a spreadsheet. It has one scope per sheet, no cell references by name, and no scripting. Its refusals are deliberate: rather than guess, it reports units that cannot be combined or a tag that has no lines as errors.
